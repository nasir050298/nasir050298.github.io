# Nasir Uddin Khan — Portfolio v3

A free GitHub Pages website made with React 19, TypeScript, Vite, Tailwind CSS 4 and Lucide React.

## Pages

- `/` — Home, About, Contact
- `/research/` — Research interests and selected manuscripts
- `/engineering/` — Selected software projects and engineering skills

## Local development

Requires Node.js 22. The package lockfile will be generated by npm install. This source bundle was not build-tested in the artifact environment; verify the first GitHub Actions build.

```sh
npm install
npm run dev
```

Open the localhost URL shown in your terminal.

To test the production build:

```sh
npm run build
npm run preview
```

## Deployment to nasir050298.github.io

1. Back up your existing `main` branch, or download your existing files.
2. Upload **the contents of this project folder**, including the hidden `.github/workflows/deploy.yml` file, to the root of `nasir050298/nasir050298.github.io`.
3. Commit to `main`.
4. Under **Settings → Pages → Build and deployment**, change **Source** from `Deploy from a branch` to **GitHub Actions**.
5. Watch the **Actions** tab for `Deploy portfolio to GitHub Pages`.
6. When successful, visit `https://nasir050298.github.io`.

Do not upload the ZIP as one file. GitHub's browser upload can omit hidden folders if you select files manually; make sure the workflow is committed. A local Git command is safer:

```sh
git clone https://github.com/nasir050298/nasir050298.github.io.git
cd nasir050298.github.io
# Copy all contents of this ZIP into this directory, replacing old files.
git add -A
git commit -m "Migrate portfolio to React TypeScript and Vite"
git push origin main
```

The build outputs `dist/index.html`, `dist/research/index.html`, and `dist/engineering/index.html` using Vite multi-page inputs. This permits clean paths without SPA 404 tricks.

## Content and privacy

- Current visual project banners are **designed placeholders**, not verified screenshots.
- Research manuscript statuses come from the supplied CV and are not presented as accepted papers.
- Verify paper and demo links before publishing.
- The included `public/cv.pdf` is the user-supplied CV and may expose phone/contact information publicly. Replace with a public-safe version if needed.
- Update `src/data/content.ts` to maintain project and research information.
- No hosting bill, backend, or paid services required.
